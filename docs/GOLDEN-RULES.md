## 2. 我们怎么干（方法论、开源规范与绝对红线）

### 2.1 产品与工程铁律

- **拒绝画蛇添足与自造规则**：
  - 局域网按需启动工具（如 `:8787` 网页商店）**严禁擅自加多余的安全限制、安全测试或繁琐防线** (`2026-11-24 [agy:2e4804b0 step=104, 145]`)；
  - **严禁 Agent 自造规则**，每条硬限制必须能追溯到用户 `[H]` 原话或真实物理/安全底线 (`2026-11-25 [omp:01a21072 L1036]`)。
- **图标与主屏洁净**：修改版应用（如 YouTube TVL）与 Demo 应用必须有可辨识的定制图标（如反色处理），及时清理无图标测试残留应用 (`2026-11-24 [agy:2e4804b0 step=160, 196, 359]`)。
- **真机视觉验收优先**：TV 端应用必须以**进入应用 → 实机截屏 → 按画面确认进入界面**为准，不能只凭命令返回码 (`2026-11-24 [omp:01a20de4 L197]`, `2026-11-25 [agy:2e4804b0 step=431, 742]`)。

### 2.2 开源项目治理规范

- **License**：统一采用标准纯 **MIT License**（与上游 `opa334/TrollStore` 主体、`Relaxin`、`ChOma`、`ipatool` 一致），并在 `LICENSE` / `NOTICE` 写清版权归属与免责声明 (`2026-11-25 [agy:2e4804b0 step=854, 931, 1036]`)。
- **Fork 关系与规范 Credit**：开源项目重在 **Fork 关系**与**规范引用**；所有引用上游（`TrollStore`、`TrollStore-tvOS`、`Relaxin`、`roothide`、`Procursus`、`ipatool`、`fairplay-decrypt`、`vphone-cli`）必须贴完整仓库 URL、许可证与简明用法，旁注归属准确（`vphone-cli` 须注明按当前最新版本仅支持约 tvOS 27 左右）(`2026-11-25 [agy:2e4804b0 step=825, 838, 931, 936, 954]`)。
- **洁净室与零敏感信息**：公开仓不含任何第三方版权代码/IPA/凭据/个人路径/个人 IP/密码；历史提交若混入敏感信息须经 Git 历史过滤彻底清除 (`2026-11-25 [agy:2e4804b0 step=768, 1036]`)。
- **双语文档规范**：中英文 README 与文档全套补齐，**首页顶部必须提供 `中文 / English` 语言切换引导链接** (`2026-11-25 [agy:2e4804b0 step=1036]`)。
- **CI 策略**：不强求远端 CI，接受本地 macOS 编译与本地校验 (`2026-11-25 [agy:2e4804b0 step=931]`)。
- **新仓形态**：保持 `trollstore-lite-tv` 独立稳定；未来新项目接受沿用 `TrollStore` 名称并规范 Credit，既可按复用度直接 Fork `straight-tamago/TrollStore-tvOS`，也可独立纯 MIT 建仓 (`2026-11-25 [agy:2e4804b0 step=929, 936]`)。
